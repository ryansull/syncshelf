- MCP tool `resolve_match` (#174): settle which Hardcover book a Goodreads book is, for an
  entry from `unmatched_books` or a book linked wrongly. The link is the user's own, and what
  Goodreads has for the book reaches Hardcover at once, without waiting for a run. A book
  queued by the first sync and added this way gets a read only for a real Goodreads Date Read.
  With no book, the entry is ignored until it's resolved with one. An old shelf entry is
  left in place and named.
