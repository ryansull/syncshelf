- A Goodreads library export's Read Count and Binding now do their jobs (#168). A Read Count
  one higher than last seen, with a new Date Read, adds a re-read on that date rather than
  moving the last read; one that comes with a move to Currently Reading or a finish is that
  read. Read Count never adds a read the first time it's seen, so a new book gets one read.
  Binding sets the format of later reads: the matched edition when it's that format, else
  the book's default edition for it. A correction keeps its read's edition.
