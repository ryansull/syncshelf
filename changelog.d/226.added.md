- Two new MCP tools for phase 4b (#226): `goodreads_sign_in` starts an attended Goodreads
  sign-in for your own profile and returns at once with where it got to, and `goodreads_verify`
  passes on the one-time code Amazon asked for. Signing in again is also how a bot check or a
  rejected password is cleared. Neither tool echoes the code, the password or a cookie.
