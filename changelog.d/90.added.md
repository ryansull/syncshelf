- MCP tool `update_book(book_id, status?, rating?, review?, review_has_spoilers?)` (#90):
  sets a book's shelf status (Ignored included), rating or review on the caller's own Hardcover
  shelves, adding the book if it isn't there yet, and returns each changed field's prior value.
  Unchanged fields aren't written, and each applied change logs one `change_applied` line (a
  review only as its length and a hash).
- New config key `profiles.<name>.hardcover_privacy` (`public`, `followers` or `private`, the
  default): who sees books SyncShelf adds to that profile's Hardcover shelves (#90). It applies
  to new shelf entries only.
