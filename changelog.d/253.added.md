- Goodreads library exports now run on their own schedule (#227): one every five days per
  profile, in the 02:00-05:00 window in that profile's own timezone, so the slowest Goodreads
  call SyncShelf makes happens while nobody is reading. A failed export waits for the next
  night rather than retrying sooner, and a restart keeps the due date instead of starting the
  five days again.
- `sync_now(full=True)` runs a library export straight away, instead of reporting that phase 4b
  had not arrived (#227). It needs Goodreads credentials; without them it says so and points at
  the shelf feed.
- Uploading an export with `generated_at` now also counts as a library export, pushing the next
  automatic one five days out from when that export was generated (#227). An upload without
  `generated_at` still only fills, so it changes nothing about the schedule.
