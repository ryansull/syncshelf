- MCP tools `sync_now` and `retry_failed` (#172). `sync_now` starts a Goodreads run for the
  caller's profile at once and returns its id, or reports the run already going; `full`
  (the library export) and `abs` say which phase brings them. `retry_failed` releases one of
  the caller's quarantined changes, or all of them, and queues a run straight away.
