- MCP tool `rebaseline` (#175): run a profile's first Goodreads sync again, for when it ran
  before the hand import into Hardcover had finished. It previews first (how many unmatched
  books would be matched again, and how many waiting changes would be dropped) and acts only
  on the confirm token from that preview. Confirmed, it matches the unmatched books again by
  the first sync's rules, keeps books matched or ignored by hand, takes what Goodreads shows
  now as the baseline, and sends nothing to Hardcover.
