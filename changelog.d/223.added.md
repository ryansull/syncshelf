- Phase 4b runs the Goodreads library export itself (#223): it triggers one, polls for up to ten
  minutes, downloads the CSV and stores it as a `gr_csv_auto` batch the existing sync engine
  applies. An export younger than 24 hours is reused instead, and if Goodreads refuses to start
  a new one, an export it already has is used whatever its age rather than the run failing.
