- SyncShelf now fetches Goodreads library exports itself and applies them (#227). An automatic
  export is always dated, so unlike an upload without `generated_at` its changes reach Hardcover.
  If the Goodreads session has expired, SyncShelf signs in again on its own once and retries; a
  CAPTCHA or a rejected password still waits for you to run `goodreads_sign_in`.
