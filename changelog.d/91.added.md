- `update_book` logs reads with the dates the user gives (#91): `finished_on` (implying Read)
  completes the read left open or adopts one already logged within 14 days, unless `reread`;
  `started_on` alone opens a read; `format` picks the book's audio, ebook or print edition for
  it. The reads Hardcover invents dated today when a status changes are always undone, so no
  date is ever written that the user didn't state. Read over a still-open read is refused
  (`date_needed`), as is a new read whose format isn't known (`format_needed`).
