- Goodreads status changes and their reads reach Hardcover (#161). Going Read finishes a read
  (completing the one open, or adopting one within 14 days) on Goodreads' Date Read, else the
  date Goodreads last touched the book, else the day SyncShelf first saw the change; the
  `change_log` row's `date_source` says which. Going Currently Reading opens a read the same
  way. Read → Currently Reading → Read is a re-read. A changed Date Read moves the read
  finished on the old date; a vanished one is never pushed. New reads carry the Goodreads
  edition's Hardcover edition when it has a format, else none.
