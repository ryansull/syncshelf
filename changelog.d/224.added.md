- Phase 4b can sign in to Goodreads itself (#224): SyncShelf drives a plain Chromium through the
  browser sidecar, filling the account's email and password and keeping the signed-in cookies for
  Goodreads only. A one-time code or an approval prompt leaves the session waiting, a bot check
  or CAPTCHA stops it, and a rejected password is never retried. A sign-in left waiting when the
  service restarts is reset to needing a sign-in, since no browser is still behind it.
