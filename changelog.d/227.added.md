- Two new config keys for phase 4b (#227): `cadence.csv_interval_days` (default 5) and
  `cadence.csv_window` (default `02:00-05:00`) say when a Goodreads library export is due and
  which nightly window it runs in, read in each profile's own timezone. A failed export waits for
  the next window rather than retrying sooner.
